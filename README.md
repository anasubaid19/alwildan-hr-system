# AL-WILDAN HR System

Sistem Data Kepegawaian AL-WILDAN Islamic School.

## Tech Stack
- Backend: Node.js + Express + SQLite
- Frontend: React + Vite + Tailwind CSS

## Cara Install

### 1. Clone repo
git clone <repo-url>
cd alwildan-hr-system

### 2. Setup Backend
cd backend
cp .env.example .env
# Edit .env sesuai kebutuhan
npm install
node src/index.js

### 3. Setup Frontend
cd frontend
npm install
npm run dev

### 4. First Setup
Buka http://localhost:5174
Ikuti panduan First Setup untuk buat akun pertama.

## Default Port
- Backend: 3010
- Frontend: 5174
